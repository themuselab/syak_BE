# 카탈로그 품질 보정 (2026-11-17)

하랑왁싱·메이왁싱의 기존 gallery에 클립 작성자/리뷰 작성자 프로필,
영상 썸네일, 네이버 프로모션 배너가 섞인 것을 확인했다.
수집기가 Apollo 캐시의 모든 이미지 URL을 순회한 것이 원인이다.

- 공통 `ShopPhotos` 정책을 앱 리포지토리(기존 캐시 포함)와 웹 raw API에 적용한다.
  네이버 이미지 프록시도 실제 원본 URL을 검사한다. 네이버의 매장/예약/검색광고
  이미지와 별도 업로드 이미지는 유지한다. 실제 리뷰 첨부는 변경하지 않는다.
- `web/scraper/place_photos.py`는 해당 매장의 business 출처 정지 사진만 수집한다.
  타입/출처를 확인하지 못하면 임의의 캐시 URL로 대체하지 않는다.
- `shared/catalog-exclusions.ts`의 검토된 업체 ID는 소비자 지도·검색·상세,
  예약 검색 및 SEO/전국 슬롯 수집 대상에서 제외한다. 원본 행과 고객 기록은 삭제하지 않는다.
  최초 제외: `1561251960` 누수탐지·수도배관 수리업체(광주시), 기존 오분류 마사지.
  추가 제외: `1225759020` 누수탐지·도배·석고보드 교체업체(부산 서구), 기존 오분류 마사지.
  확대 점검: `반영구시트옥상방수누수공사`라는 같은 이름의 47곳도 반영구로 오분류됨.
  관리자 목록에서 총 49개 ID와 3개 업체명 전량 대조 후 제외 목록에 반영했다.
- 서초/사당의 '파이프 재단' 업체는 아직 특정되지 않았다. 위 업체와 동일하다고 단정하지 않는다.
  이름이 애매한 정상 매장은 추측으로 제외하지 않는다.

검증: 백엔드 빌드·Jest, 수집기 `python -m unittest test_place_photos.py test_partner_refresh.py`.

추가 발견: 신규 파트너의 detail JSON은 전체 요약 스냅샷이 아니라 부분 보강 데이터다.
웹 상세 API에서 canonical shops 컬럼의 매장명·업종·좌표·리뷰 수를 합치고 필수 배열을
기본화한다. 테라리온 등 신규 파트너의 reviewTotal 누락으로 발생하는 빈 화면을 방지한다.
