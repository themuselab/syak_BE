## 원인과 재발 방지

기존 투영은 검색 분류 `categories`를 신뢰했고 원본 세부 업종을 검증하지 않았다. 이 때문에 교육·판매 등의 상호에 포함된 미용 키워드가 서비스 분류로 남을 수 있었다. 최초 전국 검색 수집기는 현재 저장소에 없어 그 수집기의 최초 분류 라인까지 확인한 것은 아니다.

- 웹 read model 및 백엔드 enrich에서 확인된 비샵 원본 업종은 등록 거부. 상호 문자열로 판정하지 않음.
- 단일 업종 데이터는 명확한 원본 세부 업종으로 투영. 복수 업종은 보존.
- 삭제 ID는 `shop_suppressions` 및 DB 트리거로 재적재 차단. API 캐시와 SEO의 이전 데이터 노출도 방어.
- 정정 17곳은 `shop_category_overrides`에 저장해 구 수집 결과의 덮어쓰기를 방지.
- 기존 가격 동기화가 이미 조회하는 페이지에서 원본 업종을 함께 저장. 추가 요청 없음.

`POST /internal/shops/details`의 선택 입력에 `sourceCategory: string`, `sourceCategoryCodeList: string[]` 추가. 확인 시각은 서버에서 기록한다. 누락 시 기존 원본 업종을 지우지 않으며, 이 API는 기존 매장의 분류나 노출 상태를 자동 변경하지 않는다.
